# Мир Дяди Тома

Desktop-first одностраничный сайт: React, TypeScript, GSAP + ScrollTrigger, CSS, Vinext/Vite.

## Запуск

```sh
npm ci
npm run dev
```

Production: `npm run build`.

## Структура

- `app/page.tsx` — интерактивные сцены, единая обратимая GSAP timeline, hotspots, каталоги, навигация.
- `app/globals.css` — композиция, desktop breakpoints, небольшие экраны, reduced motion.
- `app/sprite-clips.json` — контуры отображения персонажей из атласов. Исходные растровые изображения не изменены.
- `public/` — официальные логотипы, storyboard, фон и производные персонажи из предоставленных референсов.
- `app/layout.tsx` — русскоязычные метаданные.

## Визуальные источники

Hero: `photo_2026-09-06_22-35-48.jpg`; театральный переход: `photo_2026-09-06_22-38-50.jpg`; финальные позы: `ChatGPT Image 6 сент. 2026 г., 23_53_57 (2).png`; 16-кадровый storyboard: `photo_2026-09-06_22-39-33.jpg`.

Официальные файлы логотипов взяты из папки проекта без перерисовки. Текстовый логотип отображает первый утверждённый вариант посредством CSS-кадрирования. Для сцены подготовлены ImageGen фон без UI и атласы персонажей по референсам. Генератор выдал RGB; SVG clipPath ограничивает отображение исходных пикселей силуэтами. Для идеальных краёв в крупном масштабе эти два атласа рекомендуется заменить мастер-файлами с настоящей альфой.

Штора и канат отображают фрагменты предоставленного storyboard. Это не видео: все фазы перехода контролируются scroll position. Фон финала использует подготовленную ферму; графические панели под логотипами пока не воспроизводят деревянные таблички финального макета буквально.

## Оставшиеся исходные данные

- Официальные контакты и прямая ссылка магазина Ozon не представлены; контакты обозначены честно, Ozon открывает поиск бренда.
- CTA ведут в работающие внутренние каталоги по категориям. Полные товарные страницы, цены и карточки упаковок не входят в текущий слой.
- Прозрачные мастер-файлы персонажей улучшат края масок; текущие контуры функциональны, но не заменяют художественную ретушь.

## Проверка

Production build. Общая TypeScript-проверка требует типов Cloudflare Workers из окружения; ошибок в файлах интерфейса проверка не показала. Браузерная визуальная проверка не выполнялась.
